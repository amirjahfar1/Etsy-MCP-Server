# AI-generated artwork — official Etsy policy

Confirmed straight from Etsy's Seller Handbook article "What's Etsy's Stance on AI
Creations?" (9 Jul 2024, fetched 2026-08-06).

## The rule

Etsy allows sellers to use their **own original prompts** combined with AI tools to
create the **artwork/design of an item itself** (e.g. an AI-generated fantasy scene, a
custom AI pet portrait). This is about the *product's design*, not about using AI to
write listing copy.

**Mandatory disclosure**: if an item was created using AI, the seller **must disclose
this within the listing description**. There's no specific wording mandated by this
article — just that the fact must be stated.

**Explicitly prohibited**: selling **AI prompt bundles** on their own (the prompt text
without the finished artwork) — Etsy considers the prompt part of the creative
process, not a sellable product on its own.

**Nudity/sexual content**: AI-generated depictions still fall fully under the
Prohibited Items Policy, same as any other content, plus Etsy's general prohibition on
content that infringes someone's privacy/publicity/personal rights.

## What this does and doesn't apply to in this project

- **Does not apply** to Claude drafting a listing's title/tags/description text — that
  is AI-assisted *copywriting*, not AI-generated *product artwork*, and isn't what this
  policy is about.
- **Does apply** if a product's actual design/graphic (the thing printed on a shirt,
  the digital SVG file being sold, wall art, etc.) was itself produced with an AI image
  generator, whether sourced that way by a supplier or generated in-house.
- **Action for any listing-creation skill** (`etsy-create-listing`,
  `etsy-new-listing-copywriter`, `etsy-copy-listing`): if the product's design/artwork
  is known or stated to be AI-generated, ask whether to include an AI-disclosure line
  in the description, and add one if so — this isn't currently part of the
  Completeness Gate in [[etsy-seo-standards]] and should be treated as a real
  compliance gap to close, not an optional nicety, given how strict Etsy's current
  enforcement climate is proving to be for this shop.
