# Aesthetic / style taxonomy — shared reference for product ideation & listing styles

Saved 2026-08-13 at the user's request, after discussing shop positioning for the
`Anas` account (pivoting to gothic/vintage/unique jewelry). This is a working
reference list of the aesthetic/style "types" a jewelry, clothing, or general
accessory product can be positioned around — the same kind of category as "gothic"
or "vintage." Read this whenever the user asks something like "rings/jewelry/clothing
types kaun kaun c hoti hain" (what types/aesthetics exist), or when brainstorming a
new product's angle (`etsy-product-ideation`), picking a shop's niche/positioning, or
filling a listing's `styles` field (`etsy-new-listing-copywriter`, `etsy-create-listing`).

This is a style/aesthetic taxonomy, not a physical-construction taxonomy — it answers
"what vibe is this product going for," not "what shape/build is this ring/garment"
(e.g. it doesn't cover ring construction types like signet/band/wrap/cocktail, or
garment cuts like cropped/oversized — those are product-specific and belong in that
product's own listing details, not here).

**Etsy field note**: the `styles` field on `create_draft_listing` accepts **up to two**
style strings, each ≤45 characters, letters/numbers/whitespace only (no punctuation) —
see CLAUDE.md's `create_draft_listing` gotchas. When picking styles for an actual
listing from this list, pick the **two** closest matches, not the whole list.

## Dark / alt / edgy

- **Gothic** — crosses, skulls, dark stones, black metals, cathedral/cross motifs
- **Witchy / Occult** — moons, pentagrams, tarot symbolism, coven/spellwork themes
- **Punk / Grunge / Alt** — chunky chains, spikes, safety-pin styling, distressed look
- **Cyberpunk** — futuristic, metallic, geometric, neon-on-black
- **Dark Academia** — vintage-scholarly, tweed/leather tones, old-book aesthetic
- **Egirl / Eboy** — chains, chokers, grunge-cute mashup, alt streetwear
- **Emo** — 2000s-throwback, black/red palettes, band-inspired

## Vintage / historical / retro

- **Vintage / Antique-inspired** — filigree, aged brass/bronze, heirloom look
- **Art Deco** — geometric lines, 1920s glam, symmetrical patterns
- **Victorian / Renaissance / Baroque** — ornate detail, lockets, cameo-style
- **Steampunk** — gears, cogs, industrial-Victorian mashup
- **Retro decades** — 70s/80s/90s specific throwback motifs and palettes
- **Y2K** — chunky, colorful, early-2000s throwback

## Fantasy / mythical / occult-adjacent

- **Fantasy / Medieval** — dragons, swords, crowns, castle/kingdom motifs
- **Celestial / Astrology** — moon phases, zodiac signs, stars, sun/moon pairs
- **Nature / Botanical / Woodland** — leaves, flowers, animals, forest motifs
- **Mermaidcore / Fairycore** — iridescent, whimsical, fantasy-nature blend

## Soft / romantic / everyday

- **Minimalist** — thin bands, delicate chains, dainty, low-detail
- **Bohemian (Boho)** — layered, earthy stones, tribal-inspired patterns
- **Cottagecore** — mushrooms, florals, soft vintage-cozy, pastoral
- **Coastal / Coastal Grandma** — beachy, neutral tones, relaxed elegance
- **Light Academia** — soft-scholarly, cream/beige tones, gentle vintage
- **Preppy** — collegiate, clean lines, classic color-blocking

## Bold / statement / culture-driven

- **Maximalist / Statement** — bold, oversized, deliberately eye-catching
- **Western / Cowboy-core** — turquoise, leather, southwestern motifs
- **Streetwear** — bold graphics, urban, logo-adjacent (without infringing — see
  CLAUDE.md's trademark/branding standing rule before using any real brand name)
- **Athleisure / Sporty** — sport-inspired, functional-looking, casual-bold
- **Old Money / Quiet Luxury** — understated, monogram-adjacent, "expensive-looking"
  without logos

## Spiritual / religious / symbolic

- **Religious / Spiritual** — crosses, hamsa, evil eye, prayer beads, om symbols
- **Kawaii / Japanese-inspired** — cute, pastel, character-adjacent (careful re:
  licensed characters — same trademark rule applies)

## Cross-cutting modifiers (stack with any category above, not a category on their own)

- **Personalized / Custom** — name, birthstone, initials, custom text — applies across
  every aesthetic above
- **Unisex / Gender-neutral** — applies across every aesthetic above; relevant for the
  `Anas` shop's "for men and women" positioning specifically

## How this applies to the Anas shop's positioning (context, not a rule)

The user's stated direction for `Anas` — "gothic, vintage, unique" — blends three
categories above: **Gothic** (Dark/alt) + **Vintage/Antique-inspired** (Vintage/
historical) + **Fantasy/Medieval or Witchy/Occult** (Fantasy/mythical). This is a
coherent, established Etsy niche (dark academia / dark fantasy jewelry buyers overlap
heavily across these three) and matches the shop's existing dragon-ring listings.
